# SDD 2.4.1 - Telegram dialog names for chat list

## 1.0 Idea

Populate chat summaries with meaningful titles from Telegram dialogs so the
left chat list shows names instead of raw chat IDs.

## 2.0 Structured spec

### 2.1 Scope

- [x] (2.1.1) Fetch dialogs after auth to obtain peer titles and kinds.
- [x] (2.1.2) Resolve chat titles from peer name, then username, then chat ID.
- [x] (2.1.3) Map Telegram peer kind into cache `ChatPeerKind`.
- [x] (2.1.4) Capture last message id and timestamp when available.
- [x] (2.1.5) Capture unread counts for dialog entries when available.
- [x] (2.1.6) Skip non-chat dialog folder entries.

### 2.2 Out of scope

- [ ] (2.2.1) Live updates for chat title changes or avatar changes.
- [ ] (2.2.2) Partial dialog pagination or incremental syncs.

### 2.3 Startup behavior

- [x] (2.3.1) Sync dialog summaries before starting the update stream.
- [x] (2.3.2) Refresh UI state after dialog summaries are stored.

## 3.0 Implementation plan

- [x] (3.1.1) Add a core helper to fetch dialog summaries via grammers.
- [x] (3.1.2) Add pure helpers for title resolution and peer kind mapping.
- [x] (3.1.3) Wire app startup to sync dialog summaries into the cache.
- [x] (3.1.4) Log dialog sync success or failure.

## 4.0 Test plan (generation)

- [x] (4.1.1) Unit test title resolution preference and fallback logic.
- [x] (4.1.2) Unit test peer kind mapping for user, group, and channel ids.

## 5.0 Code plan (follow-up after tests)

- [x] (5.1.1) Implement dialog summary fetcher in core.
- [x] (5.1.2) Expose dialog summary fetcher in core module exports.
- [x] (5.1.3) Update app startup to call the dialog sync helper.
