# SDD 3.2.1 - Scrollable pane refactor

## 1.0 Idea

Refactor the message list, message composer, and log window to share a reusable
scrollable pane component so future panes can reuse the same scroll behavior and
rendering helpers.

## 2.0 Structured spec

### 2.1 Scope

- [x] (2.1.1) Add a reusable scrollable pane module in the ui crate.
- [x] (2.1.2) Pane state tracks vertical and horizontal scroll offsets.
- [x] (2.1.3) Pane computes max scroll for line count and max line width.
- [x] (2.1.4) Pane renders optional scrollbars per axis.
- [x] (2.1.5) Message list pane uses vertical and horizontal scrollbars.
- [x] (2.1.6) Message composer pane uses the pane renderer with scrollbars
  disabled by default.
- [x] (2.1.7) Log window pane uses vertical scrolling and scrollbar rendering.
- [x] (2.1.8) Chat list pane uses the pane renderer with vertical and
  horizontal scrollbars.
- [x] (2.1.9) Log window pane supports horizontal scrolling and horizontal
  scrollbar rendering.

### 2.2 Out of scope

- [ ] (2.2.1) Chat list virtualization or performance tuning.
- [ ] (2.2.2) Virtualized message rendering or performance tuning.
- [ ] (2.2.3) New keybindings or focus behavior changes.

### 2.3 Interaction behavior

- [x] (2.3.1) Scroll offsets are clamped to computed max scroll values.
- [x] (2.3.2) Scrollbars render only when enabled and there is space.
- [x] (2.3.3) Message selection, search, and cursor behavior stay the same.
- [x] (2.3.4) Log window hotkey and scroll controls stay the same.

### 2.4 UI state model

- [x] (2.4.1) Pane state stores viewport size and page size used by scroll logic.
- [x] (2.4.2) Message view state delegates scroll offsets to pane state.
- [x] (2.4.3) Log view state delegates scroll offsets to pane state.
- [x] (2.4.4) Composer uses pane state for consistent rendering helpers.

## 3.0 Implementation plan

- [x] (3.1.1) Add `ui/src/pane.rs` with `PaneState`, `PaneConfig`, and
  `PaneMetrics` (line count, max line width) for scroll calculations.
- [x] (3.1.2) Implement `PaneState` helpers to clamp offsets and compute max
  scroll for vertical and horizontal axes.
- [x] (3.1.3) Add a pane render helper that: builds a `Paragraph`, applies
  scroll offsets, returns the text area, and draws optional scrollbars.
- [x] (3.1.4) Update `ui/src/view.rs` message list rendering to use the pane
  module for scrolling and scrollbar drawing.
- [x] (3.1.5) Update `ui/src/view.rs` composer rendering to use the pane
  module with scrolling disabled by default.
- [x] (3.1.6) Update `ui/src/view.rs` log window rendering to use the pane
  module with vertical scroll enabled.
- [x] (3.1.7) Update `ui/src/interaction.rs` to use pane max scroll helpers for
  message and log scrolling.
- [x] (3.1.8) Update `app/src/tui.rs` to clamp message/log scroll offsets using
  pane helpers and keep viewport/page sizes in sync.
- [x] (3.1.9) Remove duplicate scroll helpers replaced by the pane module and
  adjust tests to the new APIs.
- [x] (3.1.10) Update chat list rendering to use the pane module with
  scrollbars.
- [x] (3.1.11) Enable horizontal scroll and scrollbar rendering for the log
  window pane.
