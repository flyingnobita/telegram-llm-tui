# SDD 3.6 - Chat List Search

## 1.0 Idea

Enable users to quickly find a chat by typing its name. Triggered by `/` when the chat list is focused. Filters the list in real-time.

## 2.0 Structured spec

### 2.1 Scope

- [x] (2.1.1) **Activation**: Pressing `/` while the Chat List is focused enters "Chat Search" mode.
- [x] (2.1.2) **Input**: A search query can be typed.
- [x] (2.1.3) **Filtering**: The Chat List only shows chats whose titles match the query (case-insensitive substring match).
- [x] (2.1.4) **Selection**:
    - If the currently selected chat is in the filtered results, it remains selected.
    - If not, the first result is selected.
    - If no results, selection is None (or "No results" shown).
- [x] (2.1.5) **Navigation**: `Up/Down` (or `j/k`) navigates the *filtered* list.
- [x] (2.1.6) **Confirmation**: `Enter` selects the highlighted chat and returns focus to the Message View (or simply exits search mode but keeps chat list focused, depending on desired UX. Standard TUI behavior: select and maybe focus message view).
    - Decision: `Enter` selects the chat and clears the search mode (returning to normal Chat List focus), but does *not* auto-focus the message view unless configured. Actually, `3.5` says "Enter: Select" for Chat List. So we should maintain that.
- [x] (2.1.7) **Cancellation**: `Esc` clears the search query, shows all chats, and exits search mode.

### 2.2 UI Changes

- **Chat List Title**: Updates to show `Chats (search: <query>)`.
- **Chat List Items**: Only matching items are rendered.

### 2.3 State Model

- **New State**: `ChatSearchState` in `UiState`.
    - `is_open: bool`
    - `query: InputState`
- **Focus**: New `UiFocus::ChatSearch` (or reuse generic search focus if applicable, but specific focus allows specific key hints).

## 3.0 Implementation plan

- [x] (3.1.1) **State Definition**: Add `ChatSearchState` to `UiState` and `UiFocus::ChatSearch`.
- [x] (3.1.2) **Logic Update**: Update `UiCacheBridge::refresh` (or `map_chat_summaries`) to accept a filter query.
    - Logic: `summaries -> filter(query) -> sort -> map -> state.chats`.
- [x] (3.1.3) **View Update**:
    - Update `view::draw` to show search query in Chat List title.
    - Update `view::key_hints_for_focus` for `ChatSearch`.
- [x] (3.1.4) **Input Handling**:
    - In `app/src/tui.rs` (or `input.rs` wiring):
        - `UiFocus::Chats` + `/` -> Switch to `UiFocus::ChatSearch`, set `chat_search.is_open = true`.
        - `UiFocus::ChatSearch` + `Esc` -> Switch to `UiFocus::Chats`, clear query, `is_open = false`.
        - `UiFocus::ChatSearch` + `Enter` -> Switch to `UiFocus::Chats`, `is_open = false` (keep selection).
        - `UiFocus::ChatSearch` + Char -> Update query, trigger refresh/re-filter.
        - `UiFocus::ChatSearch` + Up/Down -> Change selection in filtered list.
