# SDD 3.7-3.9 - Unified Keybindings

## 1.0 Idea

Enable consistent navigation and interaction keybindings across all keymap styles (Vim and VSCode/Standard). Specifically, `j`/`k` for vertical navigation, `/` for search, and `i` for focusing the composer should work regardless of the selected keymap style.

## 2.0 Structured spec

### 2.1 Scope

- [x] (2.1.1) **Universal j/k**: `j` (down) and `k` (up) should navigate lists (Chats, Messages, Logs) in _both_ Vim and VSCode styles, in addition to Arrow keys.
- [x] (2.1.2) **Universal /**: `/` should trigger search in Chats and Messages panes in _both_ styles (VSCode users might also expect `Ctrl+f`, which is already there, but `/` is a good quick alternative).
- [x] (2.1.3) **Universal i**: `i` should focus the Composer from Chats or Messages panes in _both_ styles.
- [x] (2.1.4) **Conflict Resolution**: Ensure `i`, `/`, `j`, `k` do not conflict with existing VSCode bindings if any (VSCode usually uses modifier keys for commands, so single keys are safe unless typing in a text field).
  - _Note_: In `Composer` focus, these keys print characters. This change applies only to navigation panes (Chats, Messages, Logs).

### 2.2 Keymap Changes

| Key | Context         | Action         | Old Style | New Style |
| :-- | :-------------- | :------------- | :-------- | :-------- |
| `j` | Chats/Msgs/Logs | Down           | Vim       | All       |
| `k` | Chats/Msgs/Logs | Up             | Vim       | All       |
| `/` | Chats/Msgs      | Search         | Vim       | All       |
| `i` | Chats/Msgs      | Focus Composer | Vim       | All       |

## 3.0 Implementation plan

- [x] (3.1.1) **Refactor Interaction**: Update `ui/src/interaction.rs`.

  - Ensure these keys are handled _before_ falling back to default behavior or ensure no conflicts.
