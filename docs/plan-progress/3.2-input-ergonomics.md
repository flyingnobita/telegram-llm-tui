## 3.2.5 Logging

1. (3.2.5.1) Primary log file is `logs/app.log` (configured in
   `app/config/app.toml`).
2. (3.2.5.2) Error log file is `logs/app-error.log` (configured in
   `app/config/app.toml`).
3. (3.2.5.3) Log level uses `[logging].level` in `app/config/app.toml`
   (default `info`).
4. (3.2.5.4) Log format uses `[logging].format` in `app/config/app.toml`
   (default `plain`).
5. (3.2.5.5) Rotation uses `[logging].rotation` and size-based defaults in
   `app/config/app.toml`.
